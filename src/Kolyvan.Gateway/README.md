# Настройка моделей шлюза

Список клиентов задаётся массивом `ChatModels` в `appsettings.json`. Одна запись соответствует одному клиенту балансировщика. Можно добавлять записи с `Provider` = `OpenAI` (для OpenAI-совместимого API) или `Ollama`. Для каждой записи нужны `Endpoint` и `Model`; для `OpenAI` также нужен `ApiKey`. Порядок записей определяет порядок обхода существующим балансировщиком.

В примере сохранены обе прежние модели. Ключ внешней модели не хранится в репозитории.

Для запуска через Visual Studio щёлкните правой кнопкой по проекту **Kolyvan.Gateway** → **Manage User Secrets** («Управление секретами пользователя») и добавьте в открывшийся `secrets.json`:

```json
{
  "ChatModels:0:ApiKey": "ваш_ключ"
}
```

Выберите профиль запуска `http` или `https`: оба задают окружение `Development`, в котором ASP.NET Core загружает User Secrets. Индекс `0` относится к первой записи `ChatModels`; если порядок моделей изменится, обновите индекс. Для запуска из терминала также подходит переменная окружения `ChatModels__0__ApiKey`.
